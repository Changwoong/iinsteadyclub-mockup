ABOUT

01 / 우리는 누구냐면

좋은 음악과 아티스트의
가치를 만들어갑니다.

iiNSTEADYCLUB은 음악은 진하게, 거리는 가깝게 만드는 엔터테인먼트 클럽입니다. 임준혁, 이광석처럼 친구 같은 아티스트와 함께, 팬이 매일 행복한 이야기를 만들어요.

// decorative.viz
VALUE 01

가까운 아티스트

무대 위의 우상이 아니라, 내 이야기를 들어줄 것 같은 친구 같은 사람.

VALUE 02

음악이 먼저

화제보다 실력, 콘셉트보다 오래 남는 음악을 만들어요.

VALUE 03

같이 즐겁게

아티스트가 즐거워야 그 에너지가 무대 밖까지 전해져요.

VALUE 04

팬이 행복한 클럽

응원하는 시간이 그 자체로 기분 좋은 하루가 되도록.
